# React Day — Interview Lab

A split-pane React interview crash course: **live demos on the left**, **concepts that point at those demos on the right**.

## Run

```bash
npm install
npm run dev
```

## Study path

Work through the topic chips in order. For each concept:

1. Interact with the highlighted demo region
2. Read the explanation
3. Say the interview line out loud
4. Mark it learned

Progress is saved in `localStorage`.
